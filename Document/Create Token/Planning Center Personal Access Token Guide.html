How to Create a Planning Center Personal Access Token

A step-by-step guide for setting up the Schedule Uploader app — Planning Center Schedule Uploader v0.1.0

 

What is a Personal Access Token?
A Personal Access Token is a set of credentials that allows the Schedule Uploader app to connect to your Planning Center account on your behalf. It is similar to a username and password for the app. You only need to create this once, and you can revoke it at any time from your Planning Center account.

Part 1 — Create the Token in Planning Center

Step 1 — Log into Planning Center

Open your browser and go to https://www.planningcenteronline.com and sign in with your normal Planning Center username and password.

Step 2 — Open the Developer Tokens page

Once logged in, go directly to this address in your browser:

https://api.planningcenteronline.com/oauth/applications

This is the page where Personal Access Tokens are managed. Click on Personal Access Tokens.

Step 3 — Click “New Personal Access Token”

Click the New Personal Access Token button near the top of the page.

Step 4 — Name your token

Enter a name that describes what this token is for. We recommend:

Schedule Uploader

This name is just for your reference so you can identify it later if you need to revoke it.

Step 5 — Set API permissions — Important

Below the name field you will see a list of Planning Center apps. You must enable access for the apps listed below and set each one to the latest version available in the dropdown.

 

Important: Each app has a version dropdown. Always select the most recent date shown in the list. Using an older version may cause the app to stop working when Planning Center retires that version.

Step 6 — Create the token

Once you have set the permissions, click the Submit button at the bottom of the form.

[
SCREENSHOT: The Create button at the bottom of the form]

Step 7 — Copy your credentials

After clicking Create, Planning Center will show you two pieces of information:

  • Client ID — a long string of letters and numbers

  • Secret — another long string of letters and numbers

 

Save these now. The Secret is only shown once. If you close this page without copying it, you will need to delete this token and create a new one.

 

Tip: Copy both values and paste them temporarily into a Notepad document while you set up the app. Delete the Notepad file afterwards.

[
SCREENSHOT: The credentials page showing the Application ID and Secret fields after the token has been created]

Part 2 — Enter the Credentials in the Schedule Uploader App

Step 8 — Open the Schedule Uploader app

Double-click PlanningCenterScheduleUploader.exe to open the app.

 

Windows SmartScreen warning: If Windows shows a message saying “Windows protected your PC”, this is normal for apps that are not yet code-signed. Click More info and then click Run anyway to continue.

Step 9 — Open Settings

When the app opens for the first time, it will automatically ask you to enter your credentials. If it does not, click the Settings button in the top-right corner of the app.

[
SCREENSHOT: Schedule Uploader main window with the Settings button highlighted]

Step 10 — Enter your credentials

In the Settings dialog:

  1. Paste your Client ID into the Application ID field

  2. Paste your Secret into the Secret field

  3. Click Save

Your credentials are stored securely on your computer and are never sent anywhere other than to Planning Center when the app runs.

[
SCREENSHOT: Settings dialog with Application ID and Secret fields filled in, Save button visible]

Step 11 — You are ready

The app is now connected to your Planning Center account. You can close the Settings dialog and begin uploading schedules.

 

Need help? If you see an error after entering your credentials, double-check that you copied the full Application ID and Secret without any extra spaces. If the problem continues, contact your administrator.

Revoking the Token (if needed)

If you need to revoke access or create a new token (for example, if your credentials were accidentally shared), go back to:

https://api.planningcenteronline.com/oauth/applications

Find the Schedule Uploader token in the list and click Delete. Then follow this guide from Step 3 to create a new one.
